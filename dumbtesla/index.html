DumbTesla

Automotive Privacy & Telemetry Prevention

An independent research project focused on disabling telemetry and data tracking in Tesla vehicles to restore user privacy. Utilizing network analysis and custom mobile hotspot configurations, this project intercepts and blocks vehicle tracking domains while the car is in operation.

  • Conducted network analysis using Pi-hole to successfully identify and isolate specific Tesla telemetry and location-tracking domains.

  • Engineered a mobile solution to block all vehicle data transmission over a hotspot using iOS jailbreak tools (checkra1n/unc0ver) and the Harpy network management tweak.

  • Developed a targeted domain-blocking method utilizing TetherMe and custom VPN DNS rules (Windscribe R.O.B.E.R.T.) to specifically block telemetry-prd.vn.tesla.services, telemetry-prd.ap.tesla.services, and location.teslamotors.com.

  • Authored comprehensive, step-by-step technical documentation and video tutorials to share these privacy methods with the open-source community.
